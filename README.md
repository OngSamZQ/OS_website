# Sam Ong — personal website

Responsive personal website covering operations, project delivery, data science and AI.

## Local preview

Open `index.html` in a browser, or run `python -m http.server 8766 --bind 127.0.0.1` from this directory.

Static HTML and CSS; no build step required. Google Fonts has local font fallbacks. Contact links open email or LinkedIn; no form backend or analytics is configured.

Biography, project dates and education were updated from Sam’s LinkedIn profile on 23 September 2026. Earlier logistics projects and images are retained from the original portfolio.
